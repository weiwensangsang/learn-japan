# 五十音认读考试（本地）

在仓库根目录运行：

```powershell
node web/kana-exam/serve.cjs
```

打开 [本地页面](http://127.0.0.1:4173)。也可直接打开 `index.html`，页面不需要联网或安装依赖。

选择题库后开始，默认每局 **20 题**；范围不足 20 字时按实际字数出题，**同一局同一个字只出现一次**：

- [平假名](http://127.0.0.1:4173/?script=hiragana)：46 个基本平假名，单独练习。
- [片假名](http://127.0.0.1:4173/?script=katakana)：46 个基本片假名，单独练习。
- [平片混合](http://127.0.0.1:4173/?script=mixed)：合并为 92 字，随机混合出题，作为进阶练习。

“五十音”指题库类别；现代基本假名每套各 46 字，不表示每局做 50 题。

- 看字选读音：随机显示一个假名，下面提供四个不同的罗马字读音。点击选项或按数字键 1–4 即直接进入下一题；跳过也直接进入下一题，最后一题作答后自动判卷。
- 每题只有一个正确选项；「を／ヲ」按实际读音 o 出题，回看时注明常用罗马字写法 wo。不会把 o 和 wo 同时列为选项；混合模式的同音选项也会去重。
- 浏览器有日语语音时，答完后可听合成示范音；不评判口头发音。
- 全部完成后统一显示正确率、每题正确／错误、你的选择与正确读音、字形对照及个人速记提示。中途不显示答案；提前退出不会判卷或保存成绩。
- 默认从当前题库抽 20 个不重复的字。混合模式每轮会包含两种假名；也可选行，范围不足 20 字时全部各考一次。例如选 5 个字，本轮就是 5 题，不重复补题。生成试卷时先按假名字形去重；混合模式中同音的不同字形仍是不同题目。
- 结束后可只重考错字，每个错字只考一次，按实际错字数判卷。混合错字若只有一种假名，就只考这些错字。
- 三种模式分别记住当前页面所选行。最近成绩按题库分别显示，每种保留最近 10 次；清除只影响当前题库。原有平假名成绩保留。记录存于浏览器本地，不上传。

提示来自 `docs/gojuon-learning-method.md`，两套题库都使用用户选定的提示。修改主文档后在仓库根目录运行：

```powershell
node web/kana-exam/sync-data.cjs
```

验证：

```powershell
node --test web/kana-exam/core.test.cjs
```

可用环境变量 `KANA_PORT` 更改端口；服务只监听本机地址。
