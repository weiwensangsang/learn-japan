# 五十音平假名认读考试（本地）

在仓库根目录运行：

```powershell
node web/kana-exam/serve.cjs
```

打开 [本地页面](http://127.0.0.1:4173)。也可直接打开 `index.html`，页面不需要联网或安装依赖。

- 看字选读音：随机显示一个平假名，下面提供四个不同的罗马字读音。点击选项或按数字键 1–4 即直接进入下一题；跳过也直接进入下一题，第 20 题作答后自动判卷。
- 每题只有一个正确选项；「を」按实际读音 o 出题，回看时注明常用罗马字写法 wo。不会把 o 和 wo 同时列为选项。
- 浏览器有日语语音时，答完后可听合成示范音；不评判口头发音。
- 每局固定 20 题，全部完成后统一显示正确率、每题正确／错误、你的选择与正确读音、易混字形对照及个人速记提示。中途不显示答案；提前退出不会判卷或保存成绩。
- 默认从 46 字中抽 20 个不重复的字；也可选行，范围不足 20 个时先遍历所选字，再随机重复凑满 20 题。
- 结束后查看正确率、错字、个人速记法、示范音，也可只重考错字。最近记录存于浏览器本地，不上传。

提示来自 `docs/gojuon-learning-method.md`。修改主文档后在仓库根目录运行：

```powershell
node web/kana-exam/sync-data.cjs
```

验证：

```powershell
node --test web/kana-exam/core.test.cjs
```

可用环境变量 `KANA_PORT` 更改端口；服务只监听本机地址。
