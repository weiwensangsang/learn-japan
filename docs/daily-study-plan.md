# 前两周N1框架与核心词汇覆盖计划

目标是面向 JLPT N1，在 14 天内快速浏览 2,000 个核心词，同时讲清主要语法、阅读与听力框架。每天 2 小时，四块各 30 分钟，共 28 小时。2026-10-09 用户确认本计划；替代此前按四周基础主题慢速推进的安排。

第一轮以“见过、看着眼熟”为目标，极快速扫过既定目录：2,000 个核心词，以及面向 N1 的主要语法、阅读、听力框架。不要求理解透、记住或独立使用。只给识别所需的简短含义、读音和代表例子；详细解释按用户提问展开。第一轮只覆盖：简短讲解、看例子、听示范。不做题、不测验、不要求当场背熟、不逐句反复确认。用户有疑问就当场解释，再继续推进。当前工作范围只有这第一轮，不自动安排后续刷题阶段。两周完成的是内容浏览和框架总览，不是 N1 熟练度。

## 每天四个半小时

| 内容 | 每天覆盖什么 |
| --- | --- |
| 词汇与汉字读音 | 按批展示核心词的常见写法、读音、简明意思，词根与主题成组；重点词补搭配，其余不逐词展开长讲解。提供示范读音。 |
| 语法 | 集中讲当天结构、变化规则、关键区别，附有读音和意思的对比例句；从基础直连高级表达。 |
| 阅读 | 示范长句拆解、助词关系、修饰、指代和文章逻辑，直接讲解，不要求先作答。 |
| 听力 | 听示范并对照原文，讲发音变化、场景表达、信息组织和意图，不做选择题或听力测验。 |

四块以 N1 理解要求组织。基础知识按理解高级材料的需要讲清，不逐级安排 N5–N2 课程或考试。假名、拗音、促音、长音等嵌入相关词汇和听力讲解。

## 两千词的分配

词表已整理保存：[总表与每日入口](../vocabulary/README.md)、[完整词表](../vocabulary/core-2000.md)、[第 1 天](../vocabulary/days/day-01.md)。按词表编号推进，不把词表生成状态当成用户已经浏览完成。

前 12 天各浏览 143 个新词，最后两天各 142 个，共 2,000 个。词汇块累计 7 小时，相当于平均每词约 12.6 秒；按紧凑词表与音频成批浏览，不为每个词逐一讲历史、扩展和提问。用户提出的疑问占用实际时间，未覆盖的词条如实记录，不虚报完成。

词表面向 N1 优化，采用初步试题词频排序、JMdict 常用词条和读音匹配，剔除异常形式并归并写法变体，选定 2,000 个独立词条。中文简义含机器辅助和人工修订，保留英文词典对照。当前统计存在缺失、OCR 和分词误差，课程词表不是未清理的机器前 2,000 项，也不宣称逐义项人工审校。2,000 是首轮选定范围，不代表所有高频词或 N1 全部词汇。

## 十四天框架顺序

| 天数 | 语法主线 | 阅读与听力配套 |
| --- | --- | --- |
| 1–2 | 文字与发音、句子骨架、核心助词 | 词与句子边界、话题与谓语、假名对应声音 |
| 3–4 | 动词分类与活用、时态、否定、形容词 | 找谓语，识别句末变化，听否定和过去表达 |
| 5–6 | て形、状态、意愿、能力、请求与规则 | 串联动作，理解持续状态、允许与禁止 |
| 7–8 | 条件、原因、转折、比较 | 识别逻辑连接、范围和条件，听转折后的信息 |
| 9–10 | 名词修饰、引用、授受、被动与使役 | 拆长句，跟踪动作参与者和引用内容 |
| 11–12 | 敬语、高级语法的主要表达类别 | 理解立场、语气、限定、评价和间接表达 |
| 13–14 | 高级结构串联、N1考点地图 | 文章主张与依据、信息检索、听力意图与任务特点 |

每个两天区间均浏览 286 个词；最后两天浏览 284 个词。结构总览不宣称包含每一条高级固定表达。复杂表达按功能组织，避免孤立罗列大量句型。
