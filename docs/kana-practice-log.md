### 当次练习表现

- あ、い、え、か：单字提问时答对。
- き、け、お：补充来源和提示后答对，随后再次答对。
- こ、く：出现过把「こ」答成 ke、ku 的情况；对照“こ 上下两段、く 一道尖角”后，两字均再次答对，之后「こ」也答对。
- う：初次答对，后续又答成 no；提示“う 上面有一小笔、の 一笔绕回”后答对，穿插「え」后再次答对。
- さ、し：第一次提问时未能回答；分别提示「左 → さ sa」「之 → し shi」后能答对，穿插其他字后也答对。
- す：首次提问未能回答；已介绍「寸 → す su」，用户随后结束当天学习，尚未作答验证。

这些结果表示当次练习中的进步，不标记为长期熟练或肌肉记忆。「の」只作为对照出现，未单独检查。

2. 从「す」继续训练；忘记时补充「寸」的来源和形状提示，再穿插已学字复查。

4. 后续补充实际音频听辨和词内认读；根据真实表现更新记录。

### 本次形成的训练办法

讲解时可以每行一起看；认读训练采用一字一问、即时纠错、穿插后再问。来源汉字和形状对照用于卡住时找回读音，熟悉后减少提示。紧接着照提示答对与隔开后答对分开记录；聊天中的正确罗马字不等于发音已经准确。
