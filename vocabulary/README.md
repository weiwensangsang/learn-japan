## 如何选择

以已获取的 2016–2025 年 N1 材料中的初步词频为排序依据，核对 JMdict 常用词条，过滤分词碎片、异常词形、失配读音和罕见旧读音，再归并同一词典词条的写法变体。最后得到 2,000 个独立 JMdict 词条。词频有缺卷、OCR、题目指令和合订内容重复等影响，具体限制见[统计说明](../docs/n1-vocabulary-analysis.md)。

这是包含基础词与高级材料常见词的首批学习表，不是官方 N1 词表，也不是未经清理的机器排名前两千。高频词与少量高级表达一起服务 N1 的理解需求。语法框架另按[两周计划](../docs/daily-study-plan.md)推进。

## 读音和释义

读音由词典匹配，并用原材料词形与词性辅助选择。多读音词只列常用读法，汉字在具体词组中的读音仍需结合语境。罗马字是阅读辅助，不标重音；长音等发音以日语示范音频为准。

中文简义采用机器辅助初稿后通览修订，其中 464 个词条作了人工释义修订；其余保留机器辅助释义。不是逐义项人工审校的完整辞典。CSV 中保留原英文词典释义和释义处理方式，多义词可据上下文继续修正。

词表只给第一轮识别所需的常见义，不能把同形汉字直接套成中文意思；每个词的完整用法、搭配和所有含义不在这轮展开。

## 维护

`core-2000.csv` 是主表。修改词条后运行 `python3 tools/build_vocabulary.py` 更新完整 Markdown 和每日分组；脚本检查总数、独立词条 ID、必填字段、编号连续性和每日词数。学习进度与词表数量分开记录，浏览完不标记为熟练掌握。
